Key Concepts

Tiling Strategy: Instead of each work-item loading all data from global memory, work-items in a work-group cooperate to load shared 4×4 tiles into fast local memory.

Work-Item Cooperation: Each work-item loads one element into Asub and Bsub, then all work-items in the work-group can reuse these 16 values.

Memory Efficiency: Each value is loaded once from slow global memory but used 4 times, reducing memory bandwidth by 4× (16× for actual 16×16 tiles).

Synchronization: barrier(CLK_LOCAL_MEM_FENCE) ensures all work-items complete loading before computation begins.
