Key Concepts

Tiling Strategy: Instead of each thread loading all data from global memory, threads in a work-group cooperate to load shared 4×4 tiles into fast local memory.

Thread Cooperation: Each thread loads one element into Asub and Bsub, then all threads can reuse these 16 values.

Memory Efficiency: Each value is loaded once from slow global memory but used 4 times, reducing memory bandwidth by 4× (16× for actual 16×16 tiles).
